# GigResource — what automated visitors may read.
#
# Sir Peter, 28 October 2026. Three things at once, and they pull against
# each other, so the order of the groups below matters:
#
#   1. Stay fully visible to search. Google and Bing are named explicitly so
#      nobody later reads the catch-all group as applying to them.
#   2. Let Meta's AI read the public site, so GigResource can be found and
#      cited when somebody asks Meta AI for event professionals.
#   3. Ask the AI TRAINING crawlers of other companies to stay out, WITHOUT
#      touching their search crawlers. Those are different robots with
#      different names, and blocking the wrong one costs traffic.
#
# A robots file is a request, not a barrier. A company that ignores it still
# reads the site. Nothing private is defended here: accounts, dashboards,
# payments and internal data are behind authentication, which is the only
# thing that actually stops anybody.
#
# Matching rule, since it is easy to get wrong: a crawler obeys the ONE group
# whose User-agent names it, and falls back to * only when no group does. The
# groups are not combined.
