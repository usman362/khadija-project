Brix Event Coverage

GigResource · 12 October 2026 · Prepared for Peter Zylstra · replaces the 8 October version
This corrects the earlier version. That one said fifteen of the characters could never appear because no matching event type existed. It was counted against the wrong list. Counted against the full set of event types the system actually holds, 30 of the 31 match, and nothing is blocked.

1. Where the mistake came from

GigResource keeps two lists of event types, and they are not the same length.

ListHow manyWhat reads it
The short list47Only the event chooser on Post an Event, plus a few public pages.
The main list106Everything else: the request flows, the service search, the relevance ordering, the nine AI tools.

The first count was taken against the short list of 47. The characters are properly measured against the main list of 106, and against that almost all of them land.

2. How the 31 actually stand

30match an event type 1has none, and needs none 0blocked

The one without a match is ID03 Formal Event, and that is as it should be: your own guide makes it the general option for galas, corporate and formal occasions when nothing more specific applies. It is used by falling back to it, not by matching a name.

Every other character, including the ones the first version listed as unreachable, has an event behind it: Chinese New Year, Cinco de Mayo, Diwali, Juneteenth, Pride, St Patrick's Day, Club Event, Karaoke Night, Beach Party, Pool Party, Paint & Sip, Tailgate Party, Watch Party and Bachelor Party.

3. The eight newer characters

ID32 to ID39 were drawn after the first count and all eight are in use: Corporate / Business, Anniversary, Quinceañera, Bar / Bat Mitzvah, Retirement Party, Family Reunion, Concert / Live Show and Religious Ceremony.

That brings the pack to 39 characters, and the artwork brief asks for all of them.

4. What this changes for the designer

  • Nothing is on hold. The earlier brief asked for fifteen characters to be held back. That instruction has been withdrawn and the brief reissued.
  • The order in the brief is about what is wired up first, not about what is wanted. All 39 are wanted.
Still excluded: Memorial / Celebration of Life. We offer that event type and it will deliberately show no mascot. That has not changed.

5. The one thing still worth doing

The two lists disagreeing has not caused a visible problem, because the parts of the site that matter read the main list of 106. It is a loose end rather than a fault. Tidying it is a small job on our side and nothing is waiting on it.
