Where the Brix Artwork Goes

GigResource · 12 October 2026 · Prepared for Peter Zylstra
In one line: the client picks the Event Type once, on Post an Event, and from that moment the matching Brix rides along with that event on every screen that shows the event, at small size, always beside the event name and never on top of a person, a price or a signature.

1. What it looks like on a screen

One size on list rows, about the size of a small avatar, a slightly larger one on an event's own page, and a bigger celebration pose on the confirmation screen. All of these use the centre headshot; the other five views are for later.

3. What I need to place them

The reference sheets have the characters built into a layout, so they cannot be used on the site as they are. The artwork brief sets out the full specification; the short version is:

  • Six views of each of the 39 characters, 234 images in all.
  • PNG with a transparent background, no circle painted in. 512 by 512 for headshots, 512 by 768 for full body.
  • Named as the brief sets out, for example BRIX-ID01-WEDDING-HEAD-C.
  • The circle colour for each character as a hex code.
  • The plain Guide Brix, and the celebration pose.

The site uses the centre headshot everywhere today. The other five views are worth having, but they are not what holds anything up.

4. Nothing is waiting on a decision

An earlier version of this page said fifteen characters had no event type behind them and were waiting on your call about the event list. That was counted against the wrong list and has been corrected: all 39 have an event behind them, and the designer can produce the whole set.
